# 개발 세션 이력

ToolHub Studio를 처음 설계 토론부터 배포 직전까지 만든 Claude Code 세션의 대화
이력. 결정의 맥락(왜 이렇게 만들었나)을 추적하기 위한 보존용 기록이다.

- `conversation-history.md` — user/Claude 발화 + 도구 호출 요약(⚙️)을 시간순 정리.
  도구 결과 원문은 방대해서 생략(대화 흐름·결정 근거 보존이 목적). 자동 추출물이라
  `.gitattributes`에서 `linguist-generated`로 표시(diff 접힘).

설계 결정의 **정본**은 `docs/toolhub-studio-design.md` §0 변경이력·§12 원장이다.
이 이력은 그 결정에 이르는 대화 맥락을 보충한다.
